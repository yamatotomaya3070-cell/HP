メールと決済の準備

「メール送受信（Resend）」と「決済（Stripe）」について、料金・必要なもの・アカウント作成手順・開発者へ渡すものをまとめました。金額は2026年8月時点の公表価格（$1≒155円換算）です。

作成 2026-08-14 ／ 対象：運営（合同会社絆）が用意する分

お金の流れ：Resend は運営が払うメール費用（当面 無料枠内）。Stripe は固定費ゼロで、お客様が払う公開料・月額から手数料3.6%だけが差し引かれます。

1Resendメール送受信

無料枠月3,000通・1日100通
有料（Pro）$20/月（約3,000円）
立ち上げ時無料枠で十分

必要なもの

  • メールアドレス（または GitHub アカウント）
  • 独自ドメイン（例 kizuna-hp.jp）
  • ドメインの DNS 設定権限（お名前.com 等の管理画面にログインできること）
  • クレジットカード（有料プランに上げるときのみ）

アカウント作成手順

  1. resend.com にアクセスし「Sign up」（GitHub かメールで登録）
  2. ダッシュボードの Domains → Add Domain でドメインを入力
  3. 表示される DNS レコード（SPF / DKIM / MX / DMARC） を、ドメイン管理画面（お名前.com 等）にコピーして登録
  4. Resend に戻り Verify を押す（反映まで数分〜数時間）
  5. API Keys → Create API Key でキーを発行しコピー
  6. 返信受信を使う場合は MX レコードと Webhook を設定（開発側で案内します）
開発者に渡すもの：① API キー　② 認証済みドメイン名　③（受信を使う場合）Webhook の設定情報

2Stripe決済

初期・月額0円
手数料国内カード 3.6%（消費税なし）
例月額3,000円 → 108円

必要なもの

  • メールアドレス
  • 事業者情報：商号（合同会社絆）・所在地・法人番号（登記情報）
  • 代表者の本人確認書類（運転免許証／マイナンバーカード 等）
  • 入金先の銀行口座（法人口座が望ましい）
  • 事業内容の説明・サービスのウェブサイト URL

アカウント作成手順

  1. stripe.com で「今すぐ始める」→ メールとパスワードで登録・メール認証
  2. ダッシュボードで 事業者情報（法人/個人の別・商号・所在地・法人番号）を入力
  3. 代表者情報と本人確認書類をアップロード
  4. 入金先の銀行口座を登録
  5. 事業内容・ウェブサイト URL を入力し 審査を申請（承認まで数日）
  6. 商品と価格を登録（公開料5,000円の一回払い・月額サブスク）
  7. 開発者 → API キーで公開キー・シークレットキーを取得、Webhook を追加して署名シークレットを取得
開発者に渡すもの：① 公開可能キー　② シークレットキー　③ Webhook 署名シークレット　④ 登録した価格 ID

準備の順番

  1. 独自ドメインを取得

    例 kizuna-hp.jp。Resend のメール認証に必要な起点。年 約1,500円。

  2. Resend：登録 → ドメイン認証 → APIキー取得

    営業メールの送受信基盤。無料枠で開始できます。

  3. Stripe：登録 → 事業者審査 → APIキー・商品登録

    審査に数日かかるため、ドメイン取得と並行して早めに着手。

金額・手順は各社の公表情報（2026年8月時点）に基づく概算です。為替・プラン改定・画面変更で変わる場合があります。契約前に各社の最新ページで確認してください。／ 出典：Resend・Stripe 各公式、PAY.JP まとめ。
