準備チェックリスト

準備には順番があります。上から進めてください。ドメインが起点、Stripe審査は時間がかかるので並行で早めに。

  1. ドメイン名を決めて取得

    例 kizuna-hp.jp。すべての起点。これが決まると次に進めます。

  2. Resend：アカウント作成 → ドメイン認証（DNS）→ APIキー取得

    営業メールの送受信基盤。ドメイン認証まで済ませて信頼性を確保。

  3. Vercel：アカウント作成 → Proプラン契約

    サイト公開先。商用のためProが必須。唯一の必須固定費。

  4. Neon：アカウント作成 → 接続文字列取得

    本番データベース。無料枠で開始できます。

  5. Stripe：アカウント作成 → 事業者審査 → APIキー取得

    審査に数日かかるため、いちばん早めに着手。登記情報・銀行口座・身分証を準備。

  6. （任意）Anthropicに残高チャージ

    AI編集の品質を上げたい場合のみ。当面はGemini無料枠で不要。

各サービスのAPIキー・接続文字列を渡していただければ、繋ぎ込みは開発側で行います。あなたの作業は「アカウントを作ってキーをコピーして渡す」だけです。契約を待つ間に、営業メールへ添付する施設HPのスクリーンショット自動生成は先行して進められます。

金額は各社の公表価格（2026年8月時点）に基づく概算です。為替・プラン改定で変動します。契約前に各社の最新料金ページで確認してください。
